MateView Guardian 0.2.8 for Apple Silicon macOS

1. Double-click Install.command. If macOS blocks it, Control-click it and choose Open.
2. Approve the copy to /Applications if macOS asks.
3. Use the menu-bar shield to choose protection and a target speaker volume.

The app blocks only the MateView HID device 12D1:10B6. Normal Mac, keyboard,
application, headphone, and Bluetooth volume controls keep working.

Run Uninstall.command to restore the touch strip and remove the app.

This community build is ad-hoc signed but not Apple-notarized.
